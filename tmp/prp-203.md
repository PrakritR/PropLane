## Description

Found in a flow audit, 2026-09-04. **Hard dead end, and it quotes a price nobody set.**

## The chain

1. `getPropertyById(pid)` returns undefined (property unpublished, catalog not loaded on a cold browser, cache miss).
2. `managerUserIdForFee` is empty, so the **authoritative server fee preview is skipped entirely** and `serverFeeCents` stays null (`rental-application-wizard.tsx:1948-1960`).
3. `residentApplicationFeeGate` falls back to `listingApplicationFeeAmount`, which **hardcodes** `{ amount: 50, displayLabel: "$50" }` for any listing it cannot resolve (`household-charges.ts:1673-1675`).
4. `managerUserIdForPay` is also empty, so `ApplicationFeeInlinePayment` is **not rendered at all** (`rental-wizard-steps.tsx:2382-2405`).

## What the applicant sees

A demand for **$50** — a number no manager configured, invented by a fallback — and **no way to pay it**. A static banner where the card form should be. They cannot finish the application and cannot tell why.

## Why this is the worst kind of bug

It **states a price**. A hardcoded default in a money path is not a graceful degradation; it is the product quoting a figure it made up, on the screen where someone is deciding whether to pay. If they somehow did pay, it would not match the manager's actual fee.

## Fix

* **Remove the** `$50` **literal.** A fee that cannot be resolved is *unknown*, not fifty dollars. Show "We couldn't load this listing's application fee" and a retry — never a number.
* When `managerUserIdForFee` cannot be resolved, resolve it **server-side from the property id** rather than giving up; the id is right there.
* If the property genuinely no longer exists, say so and stop the wizard cleanly instead of advancing to a fee step that cannot complete.
* Never render a fee step whose payment form cannot mount — that combination should be unreachable.

## Acceptance

* No code path quotes an application fee that did not come from the manager's settings.
* An unresolvable listing produces a clear message and an exit, not a payable-looking dead end.
