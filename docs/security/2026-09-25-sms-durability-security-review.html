New		src/lib/sms/sms-projection-inbox.server.ts:273,288 advances the cursor for every scanned summary, including rows failing conversationVisible, and emits its base64 JSON tuple. When ten bounded pages end on an unauthorized row with continuation, an authorized co-manager can decode the hidden conversation UUID and its latest-event time. Inherited limitation		src/lib/manager-sms-send.server.ts:89-107 and projection detail authorize the actor at HTTP send time. src/lib/sms/owner-sms-dispatcher.server.ts:1051-1072 rechecks selected-line policy before delivery, but loadSendPolicy does not use actorUserId to re-evaluate the actor's Communication house grant.
