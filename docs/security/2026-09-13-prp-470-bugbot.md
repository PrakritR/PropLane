## Finding B1 - Medium / P2 - stale SMS authorization response permanently poisons the next viewer's initial gate

Location: `src/components/portal/pro-unified-inbox.tsx:317-330`, with the rejecting guard at line 315 and readiness dependency at lines 371-380.

`loadSms` captures a viewer epoch but processes 401/403 before comparing that epoch or initial request generation. Consequently, an outstanding viewer A request can set `smsPollHaltedRef` and `smsPollHalted` after viewer B has started a fresh initial load. The halt is component-global and never resets for a viewer change. Every subsequent `loadSms` returns false before fetching. Since this change now requires `smsOk` before revealing any Communication list, B cannot recover from an initial SMS failure through Retry even when the server is available and B is authorized. A stale auth response after B succeeds also disables B's background SMS refresh.

Reproduction, verified with a temporary RTL regression derived from the existing readiness suite:

1. Render manager Communication as A, with A's SMS response deferred; inbox/applications return successful empty collections.
2. Switch the mocked session to B and rerender the same component. B's first SMS request returns 500 and renders the initial error.
3. Complete A's old SMS request with 401.
4. Configure the next SMS response as valid 200 `{ residents: [] }` and click B's Retry.
5. Observed `smsCalls: 2, errorStillVisible: true`; expected a third SMS request and recovery. The third response was never requested.

Command: `/Users/akhilvemuri/.nvm/versions/node/v22.23.0/bin/node node_modules/vitest/vitest.mjs run tests/unit/__prp470_review_temp.test.tsx`.

Result: exit 1, one selected test failed, 13 skipped; assertion `expected 2 to be 3`. Parent explicitly authorized this narrow temporary test. It was deleted after execution; tracked source/tests were not changed.

Recommended resolution: validate current viewer/generation immediately after fetch before processing authorization status; scope/reset halt state on viewer transitions while preserving no-auto-polling behavior for a current viewer's refusal. Add a permanent deferred old-viewer 401/403 regression that asserts B can retry and poll normally.
