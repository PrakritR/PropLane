Finding

P3 / Low: the envelope read limit has a local filesystem race.

scripts/decrypt-local-qa-build.mjs:38-40 checks the envelope with lstat, then independently reopens it with readFile. If another local writer grows or replaces that path between these operations, the read can allocate beyond the intended 4 KiB limit before the subsequent size check rejects it. A swapped symlink is also followed by that second operation. This does not bypass GCM authentication or cause extraction, and is not a release blocker when the downloaded artifact directory is task-owned and not concurrently modified. Harden by opening once with O_NOFOLLOW, checking that handle, and reading at most 4097 bytes before parsing. The observation is from static review; no race reproduction was run.
