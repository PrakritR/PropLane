Evidence

The live model branch of runSmsAgentTurn now assembles base rules, assistantClockBlock(), optional resolved-record context, then existing wrapped personal instructions. It passes that assembled system prompt directly to runAgentTurn and includes it in trace prompt metadata. With no supplied test instant, the clock helper reads Date.now() when each model turn is assembled; it is neither a build-time value nor a date taken from an inbound request.

The existing Pacific helper uses Intl.DateTimeFormat with America/Los_Angeles. The pinned instant 2026-09-20 06:30 UTC therefore correctly yields Pacific calendar date 2026-09-19. The clock text expressly grounds today, yesterday, relative dates and default year. This addresses the missing-current-date context in the shared manager/resident SMS model path, for both ordinary carrier and classified test turns, independent of preview host or runtime timezone.

Existing record-context ordering is preserved. Personal instructions remain loaded by server-derived ctx.userId, validated and appended in the existing explicit lower-priority wrapper, which forbids overriding platform factual grounding, scope and confirmation requirements. The new clock adds no untrusted prompt input and changes no identity resolution, tool permissions, billing, confirmation, transport suppression or persistence. A textual clock is factual guidance for the model, not a replacement for server authorization or a guarantee against prompt injection.

Scope and validation limits

The new regression checks the Pacific date and relative-date rule, the presence of resolved context and custom instructions, and base-before-clock-before-context ordering. It does not explicitly assert custom-instruction ordering; that ordering was verified in the source helper. It tests the prompt helper rather than capturing an actual model invocation. The source call site establishes that the shared model path uses the helper.

Deterministic/precomputed replies and pending-action handling return before model prompt assembly and are unchanged. This review does not claim the separate leasing or vendor agent implementations gain a clock through this change. Runtime model QA remains with the release owner; source correctness alone cannot prove the preview symptom is resolved in generated responses.
