Required execution envelope

A timeout is failure/ambiguity, never success. Keep consumers excluded until root diagnoses and deliberately hands off. This finite process-level bound closes all pre-return socket ownership and query-stall paths by stopping the entire owned runtime. The existing database statement bounds still apply. Standalone limitation: P2 - connector verification is outside the owned deadline

scripts/security/signup-fixture-observer-publish-retained.mjs:120 awaits connectSignupObserver before assigning observer. The frozen connector connects and then performs BEGIN, identity, installation, definer and COMMIT queries before returning. Its configuration has a connection-establishment timeout but no client query or socket deadline. A TLS connection that stops delivering bytes after connection establishment can therefore stall any of these queries indefinitely; the server-side statement timeout does not bound delivery of a response over a stalled transport.

The helper's ten-second boundedQuery wrapper and error/end handlers only begin after that await. Its finally cannot close the unknown socket while the await is pending. The administrator transaction, advisory lock and private owner lock remain held, while root keeps consumers excluded. Existing tests inject an immediately returning connector and test only a query on an already returned client, so they do not cover this failure. This contradicts the plan's finite-bounds and owned-socket requirements.

Resolution for this root execution: use the process supervision contract above. For a standalone helper, provide a bounded ownership mechanism covering the connector's complete pre-return lifecycle, without changing the frozen rotation inputs. It must stop the owned connection or supervised process on timeout and must prevent a timed-out operation from continuing toward publication. A bare Promise.race is insufficient. If root uses an external process supervisor instead, make that exact bounded execution path reviewable, retain ambiguous state and exclusion on timeout, and confirm that the child process and its sockets actually stop. For a future standalone code fix, add focused evidence for a connector that establishes a connection but never returns; no secret publication may occur and no background operational process may survive the bound.
