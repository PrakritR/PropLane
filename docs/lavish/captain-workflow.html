Captain workflow

Ticket → Plan → Execute

The default pipeline for every agent pane. No code until Lavish plan is approved. Share ticket.md with a friend; review plan.html in Lavish.

① Ticket

Linear first

Every idea, bug, or task gets PRP-### before planning.

② Plan

Lavish + MD

plan.html for you; ticket.md to share.

③ Execute

Build

Keeper branch, MCP, docs, tests.

④ Review

Sandbox

localhost:3010 etc. — not prakrit yet.

⑤ Promote

prakrit

Captain approves merge to integration.

Flow

flowchart LR
  T[① Linear ticket] --> E[Export ticket.md]
  E --> P[② Lavish plan.html]
  P --> A{Captain approved?}
  A -->|no| P
  A -->|yes| B[③ Execute on keeper branch]
  B --> R[④ Review sandbox]
  R --> M[⑤ Promote prakrit]

Commands (copy-paste)

① Create ticket

npm run linear:ticket -- --chat "describe the work"

②a Export Markdown (send to friend)

npm run linear:export -- --ticket PRP-### \
  --out .lavish/plans/PRP-###-slug/ticket.md

②b Lavish plan

npm run lavish:plan -- --ticket PRP-### --title "..." --summary "..." --open
npx -y lavish-axi poll .lavish/plans/PRP-###-slug/plan.html

②c Optional public share

npx -y lavish-axi share .lavish/plans/PRP-###-slug/plan.html

③ After approval

# Captain says: approved — build
# Agent reads docs/agents/<area>.md + docs/portal-ui-system.md
# Commit on keeper branch (cursor-1 → :3010)

Per-ticket folder

.lavish/plans/PRP-###-short-slug/
├── ticket.md      ← Linear snapshot (email to friend)
├── plan.html      ← Lavish review (you + annotations)
└── assets/        ← Screenshots from Cursor chat
