Contract and behavior

The shared helper permits only pg, sharp, and @napi-rs/canvas, with lowercase 16-hex suffixes and their exact canonical targets. Canvas is precisely .next/node_modules/@napi-rs/canvas-<16 lowercase hex> targeting ../../../node_modules/@napi-rs/canvas. Zero through three unique package records are accepted. Duplicate identities, duplicate paths, extra fields, empty versions, malformed hashes, path spellings, and unknown names refuse.

Packaging accepts a real @napi-rs scope containing exactly one allowed canvas link. Inspected alias entries count toward inventory bounds. Diagnostics remain fixed enums. The entire alias tree remains excluded from tar; no archive link support was added. Dependency binding checks real alias/dependency parents and reads regular, single-link metadata with no-follow opens, identity checks, bounded bytes, and post-read consistency checks. Installed package name/version and lock version must agree. Restore and receipt verification also bind the authenticated version.

Restoration validates all records, bindings, and destination absence before writes; creates only fixed missing parents with mode 0700; and uses exclusive symlink creation. On later failure it removes its own links and newly created empty directories in reverse order, guarded by file and ancestor identities. Existing destinations and parents are preserved. Installer preflight binds dependencies before publication, rejects alias-tree directories before restoration, then verifies only expected aliases and parents. Receipt checks repeat bindings and retain existing provenance, immutable digests, target, lock SHA, and encryption checks.
