C2 · P2 · A fresh property target can autosave without its published version pin

Switch from an existing A application to a previously unused B that has a published template. While the authorized lookup is pending, the property-change callback sets the form to B with no pin and holds autosave. The pin effect runs at this point and returns because restoration is pending. When lookup confirms no existing B row, the callback saves a fresh B form, still without a pin, and clears pending. The pin effect depends on property/type/template ID, but none of those changes on completion, and it does not depend on pending. Autosave resumes with no template ID/version. B then resolves whatever publication is current instead of preserving the version at application start.

Evidence: pin effect and dependencies, lines 556-566; fresh target saved before a pin is selected, lines 1391-1410; pending B state, lines 1413-1420; unpinned publication resolution.
