Changes

The packager now rejects regular file paths that cannot fit USTAR's 100-byte name or its slash-separated 155-byte prefix and 100-byte name. The existing ASCII and full 255-byte policies remain. Directory names remain governed by the existing policy because directory entries are not archived. This closes the reproduced BSD tar silent omission for a 101-byte basename and the no-valid-prefix-split case.

ARCHIVE refusals now distinguish SOURCE_BYTES, TAR_BYTES, GZIP_BYTES, TAR_SPAWN, TAR_EXIT, TAR_SIGNAL, and STREAM. Diagnostics expose only closed enums and validated nonnegative bounded integers. Source byte diagnostics include previously copied bytes. Child stderr remains ignored. A byte-limit or scanner refusal keeps precedence over the signal generated by cleanup. Unknown stream errors are replaced with a fixed private diagnostic.

Ceilings, USTAR format, key handling, exact source/context binding, immutable inventory, alias allowlist, encrypted-only output, and cleanup remain in place.
