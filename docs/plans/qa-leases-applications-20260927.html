Additional release corrections

Account setup and payment recovery

Payment verification returns no account-claim credential. It emails only the stored applicant address, including cross-browser/native and webhook-first returns. Setup-token persistence errors stop welcome delivery. The submission email route never returns a newly minted token or a token-bearing mailto link based only on application ID and email.

Availability and list loading

Full shared homes cannot fall back to a property-only room selection. Server-supplied listing validation requires a configured room. Fresh checks are scoped to one public listing and rate limited. A scoped refresh preserves newer room data without changing other listings’ freshness. Failed Applications reads show Retry.
