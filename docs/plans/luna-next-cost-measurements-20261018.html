This is a measurement proposal, not an invoice, forecast or proven savings claim. The primary validation/cost report remains authoritative.

The prior synthetic READY turn had 24,561 input tokens for five output tokens. A real authenticated typed read needed two generations and cost $0.00053678, while reading roughly 24.5k cached tokens per call. These are verification samples; they show why request shape and completed-outcome accounting deserve measurement, not that the full prompt is currently the largest bill.

Collection boundaries and acceptance

Start with already recorded traces and metadata; any missing counter is a future scoped instrumentation task, not data assumed to exist. Filter production separately from release-verification, dev/test, synthetic canaries and hosted evaluator traffic. Include billable failed generations in the denominator, but keep unknown amounts unknown. Use server-side keyed/private hashes and opaque ids rather than raw messages, workspace names, phone numbers or account emails in new metric labels. Report sample size, linkage coverage and missing provider records before deriving any savings.

Suggested first deliverable: one weekly table by surface with completed outcomes, native LLM cost, calls/outcome, title overhead, cache read/write/ordinary input, actual transport/media units and reconciled provider cost coverage. A concrete change should be proposed only when the measured avoidable cost exceeds the quality/latency tradeoff. No monthly extrapolation is justified by the small verification samples.
