Readiness correction: quote directory lock order

November 4, 2026. Frozen correction to the vendor shared-line sender-authority bridge. No remote database, production, provider, configuration, source reader/contact route, branch or commit changes. Only the authority compatibility migration and its disposable PostgreSQL fixture changed.

Defect and correction

The historical consent consumer and quote response implementation acquired service before directory. Directory account attachment and both enrollment RPCs acquire directory before service. A proof could hold service while waiting for directory and a directory operation could hold directory while waiting for service, producing PostgreSQL deadlock 40P01 before any sender-revision trigger ran.

The six-argument internal consent implementation now acquires directory, then service. An idempotent compatibility DO block reads the existing three-argument response implementation and swaps only those two lock statements to directory, then service. It refuses an unrecognized prerequisite definition. Existing lifecycle, suppression, proof validity, receipt, permission and response behavior remains in the reused functions. Historical applied migration bytes are unchanged. New proof overloads retain the revision mutex first; NOWAIT revision acquisition/invalidation still converts reverse revision contention to atomic SQLSTATE 40001 refusal.

Real PostgreSQL evidence

The localhost fixture first reinstalls each old inverted function body. With a deterministic directory/advisory-lock barrier, it reproduces 40P01 for actual consume and actual proof-bearing submit response against each actual directory operation: link_vendor_directory_account, enroll_vendor_sourcing_candidate and vendor_coordination_action(kind=enroll). It restores the corrected function and runs operation-first and proof-first for all six pairs: twelve races pass without deadlock or partial writes.

When successful consent or response invalidates the sourcing worker's lease, sourcing enrollment retains its legitimate sourcing lease lost refusal. The test checks that refusal rather than relaxing the lease. Other directory operations complete, and consent/response evidence remains unique. All prior revision, auth identity, permission, exact-time-while-blocked, STOP, tuple contention, manager approval, redacted receipt and rollback scenarios remain passing.
