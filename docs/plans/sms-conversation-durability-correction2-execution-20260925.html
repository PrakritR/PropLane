Result

Manager Communication now keeps one selected SMS projection detail across list-page changes, new-message polling, and exact deep links. The merged detail loads older SMS pages without losing the saved email turns or an exhausted cursor. A newly arrived top row does not drop a displaced first-page tail already loaded below it. A multi-line selection requires an explicit work line for a send. Read progress is committed only for an inbound event the viewer actually rendered and is guarded against stale A–B–A scope responses. Both merged and standalone selected detail reauthorize on a quiet list poll even when the selected summary is unchanged; a 403/404 clears the prior transcript and selection. A revoked or ambiguous deep link ends in a terminal state. The manager nav badge reads projection unread/archive state in both flag states and is scoped to the selected workspace. When the SMS UI flag is off, the compatibility notice remains reachable. Co-manager notice replacement uses the same current authorization resolver as projection detail and checks every candidate in bounded batches of 40. Voice notes stay call annotations under a separate voice: source namespace.

The additive SQL correction serializes projection/import/delete operations per owning manager before row and provider locks, checks the complete original envelope and canonical identity on replays, and preserves exact historical identity proof when one original moves to a verified-user conversation. Historical source replay after that move remains valid; a later original joins the same conversation. The legacy alias binder requires exact owner, active summary, source namespace/id, role, line, timestamp and body proof. A mixed notice with any unmarked visible annotation does not gain a replacement alias.
