Correction

The ledger guard compares every row metadata field except statements, then the ordered SHA-256 digest of each exact UTF-8 statement. Full private captured rows, backups and receipt hashes remain unchanged. Prior generated SQL is no longer recursively embedded in later ledger guards.

A common DO wrapper deterministically chooses a delimiter absent from the complete body. Ledger, catalog, rename, invite snapshot, function and recovery blocks containing captured text use it. Static blocks without captured content remain unchanged.
