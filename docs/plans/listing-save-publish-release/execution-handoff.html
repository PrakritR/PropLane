Implemented behavior

  • The active ListingEditorV2 shows explicit Save and Publish actions on every step while preserving Back and Continue on phone and desktop.
  • Save keeps the editor open. Draft preparation accepts partial data and skips publish-only waiver-code format validation. Close still flushes unsaved work.
  • Publish performs a narrow V2 gate for street, city, canonical state, ZIP, rental model, lease type, and a rentable offering. Whole-place rent and by-room monthly/daily/weekly rent use their existing canonical helpers. Description, deposit and photos remain nonblocking.
  • An invalid Publish navigates to the relevant step, renders a footer alert, and focuses the exact actionable field after the step mounts. Repeated attempts run the same gate.
  • A synchronous lifecycle guard covers preparation/media upload and persistence, disables competing actions, and prevents Save/Publish/close races. Draft IDs and live-edit-in-place behavior remain in the existing persistence hook.
  • Persistence refusals remain visible inline and through the existing toast. Inputs remain mounted for retry.
