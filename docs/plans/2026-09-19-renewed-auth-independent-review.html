Race and regression

The new guard at the outer first-read continuation compares its captured generation and the returned identity before any session observation or signed-in marker write. If a completed concurrent renewal has advanced generation to a different identity, the old snapshot returns owner-changed instead of restoring the old identity and clearing the shared in-flight map.

  1. The first invocation completes its two reads and suspends at the deferred explicit refresh, with the original identity active.
  2. The overlapping invocation suspends in its first read. Resolving that read first queues the inner readSession continuation. Resolving the pending refresh next queues the refresh-work continuation.
  3. The read helper runs with the original generation still current, accepts the original snapshot, and queues the outer continuation behind the already queued refresh-work continuation.
  4. The refresh-work continuation observes the rotated refresh token, advances generation and writes its legitimate signed-in marker. No lifecycle callback participates.
  5. The overlapping outer continuation then sees the generation mismatch and different identity, so the new guard rejects it before another read or marker write.

The new unit assertions are discriminating. Without the guard, the overlapping invocation observes the old token and performs another signed-in marker write and second read. Even if that second read then rejects the renewed identity and the refresh count stays one, the exact three-read and marker-count assertions fail. The follow-up fresh invocation also verifies the coordinator remains usable after the rejected snapshot. The test does not merely relax the original one-refresh requirement.
