Concrete findings and next measurements

  1. Migrate remaining Anthropic inference. The largest observed cost is Sonnet/Opus runtime. This release moves supported text, reasoning, visual/document understanding, utility and growth tasks, including all six SMS identities. Specialized speech and media generation retain their capability-specific providers.
  2. Correct cache accounting. The 36 Luna observations contain 586,406 cached reads and 294,730 cache writes in metadata. Native costs total $0.089044 while metadata estimates total $0.043636. The old native generation usage omitted explicit cost components, so Langfuse treated input as uncached. New generation records must reconcile native costs with the per-request estimate. Historical figures stay intact.
  3. Reuse stable prefixes. The shared adapter sends a single leading developer prefix with an explicit cache breakpoint and implicit 30-minute caching. Continuations preserve opaque reasoning and avoid duplicate prefix text. Track cache-read tokens divided by total input per surface and compare write premiums with actual reuse.
  4. Stop redundant shadow work. The all-surface Luna flag disables the old prospect GPT comparison. A rollout should have one primary completion unless an intentional, separately bounded evaluation is active.
  5. Reconcile evaluation overhead. The now-active numeric-grounding judge preserves 100% sampling of matching summaries. Include its provider calls alongside application generations, title calls and transport/media invoices; do not assume application trace totals are the complete bill. Keep the quality signal while measuring its share of total cost.
  6. Measure useful work. Compare cost per completed turn, calls per turn, timeout/incomplete rates, tool failures, output/reasoning tokens and numeric grounding. Resume the existing paused numeric-grounding judge on Luna and preserve its rubric/rule/history. Treat the four earlier negative ratings as user-confirmed UI display issues, not model-quality failures.
