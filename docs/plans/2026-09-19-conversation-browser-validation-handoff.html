Fixture and mutation safety

  • When enabled, every fixture mutation requires the exact Supabase host emstjswhotsnyksqhqyf.supabase.co. Missing credentials or seeded prerequisites fail closed.
  • Before any write, setup verifies the existing seeded manager auth account, profile, manager role, default workspace, default-workspace Assistant row, and a property owned in that workspace. The manager browser cookie is pinned to the verified workspace.
  • The suite creates one unique temporary resident auth account with an in-memory password, resident profile and role, and a directly inserted pending Submitted application on that existing property. It invokes no lifecycle or notification route. The pending application does not enter approved-placement occupancy logic.
  • Collision checks cover the generated auth/profile identity, application/Axis ID, and all six inbox IDs before writes. Inbox fixtures use insert, never upsert.
  • Six uniquely prefixed inbox rows cover two resident sources, three manager sources, and one same-address conflicting-role source. Each carries managerUserId, propertyId, counterpartyRole, and identityProvenance. The deterministic temporary resident Assistant ID is tracked before navigation.
  • Cleanup deletes every exact inbox ID with its original owner_user_id, then the exact application, role, profile, and auth user in dependency order. Cleanup errors fail the suite. Partial setup retains ownership state for an afterAll retry.
  • The resident test allows and verifies only its real two-source mark-read POST. The manager browser path is read only: every non-GET /api/portal-inbox-threads request is aborted, including scope-less or malformed persistence that could replace or delete pre-existing manager rows.
  • Automatic AI draft requests are aborted with inbox-draft-reply route matching. Send, manager SMS, scheduled-messages, and scheduled-inbox-messages requests are separately fenced and asserted absent. Aborts reject requests; they do not return mocked successes or fabricated API data.
