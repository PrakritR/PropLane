Authority decision

The ingress record is durable source evidence and should not be discarded merely because a duplicate log is absent. Its limits matter: the original ingress writer stores left(p_body,2000), and the burst's reply_from_number can change on a later message. Receipt sender key corroborates the sender, while a matching work-line epoch proves a line existed, not necessarily which line received this SID when several were eligible. Consequently, ingress plus today's burst alone cannot universally establish unmodified original body and per-event receiver. Existing SQL trust is not new independent evidence. Do not reconstruct missing wire identity from the latest line or accept a truncated body as the full original.

Recommended implementation: one service-only, read-only durable inbound-source resolver, used by backfill, live receipt repair and burst originals. Implement the authority once as a narrowly scoped database function in a new additive migration, with a small typed server adapter; the Node backfill can call the same RPC. This also lets the historical importer invoke the identical authority within its existing transaction instead of duplicating a looser rule. The cost is one additional reviewed migration. A code-only helper would be smaller initially, but would leave the SQL importer with separate rules. The 18 missing transport copies take the notice-and-provider-proven restoration path below; unsupported records remain fatal, not exceptions to the source resolver.
