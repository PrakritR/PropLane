## Result

Manager and resident Communication now remain in an explicit loading state until every source that can contribute to the initial list has completed successfully for the current viewer. Manager readiness includes inbox rows, applications/contact directory rows, and SMS when its UI flag is enabled. Resident readiness includes inbox rows and SMS when enabled. Disabled SMS does not fetch or block readiness.

The loading list uses the existing two-pane shell and row geometry, one accessible `Loading conversations…` status, `aria-busy`, and reduced-motion-safe skeletons. Initial errors show a Retry action and never expose empty/add UI. Retry reuses normal coalescing and TTL behavior. Successful cached and background refresh paths remain available through the legacy array-returning sync wrappers.
