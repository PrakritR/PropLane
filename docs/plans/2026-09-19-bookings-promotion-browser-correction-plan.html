The final Generate promotion text button exists only on Preview (add-workspace/index.tsx:225-232), and finish() calls textComposerRef.current?.generate() (promotion-new-modal.tsx:224). It therefore silently does nothing. The composer defaults showGenerateButton=false, so there is no alternate inline submit.
