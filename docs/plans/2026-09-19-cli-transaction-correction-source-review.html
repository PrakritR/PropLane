What the correction establishes in source

The common generator emits transaction-local settings and table locks inside a PL/pgSQL DO body. Resident apply and recovery, schema reconciliation and existing recovery helpers use it. Existing ledger and function guards remain intact. No explicit transaction BEGIN or COMMIT is introduced. This matches the source-audited PostgreSQL distinction between an extended-query transaction and a top-level transaction block, while retaining the pinned CLI batch's automatic history insertion.

The observed dev failure was ERROR 25P01 on the first ledger LOCK before DDL. Root reports that the complete 211-row ledger and original RPC metadata stayed unchanged. All three actual targets are PostgreSQL 17.6. The earlier failed artifact and its receipt must not be reused for this correction.
